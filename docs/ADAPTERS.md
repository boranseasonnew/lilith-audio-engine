# Trusted model adapters

`ModelAdapter` defines manifest, stereo validation, spectral inference and disposal. MDX's implementation uses its real STFT tensor contract. `ModelRegistry.register(manifest, factory)` registers trusted compiled factories and rejects duplicate IDs; creation rejects identity mismatches. The shipped worker registers only `mdx-default`. Adapter registration from remote JSON or executable URLs is deliberately unavailable. To add a model: review weight licensing independently; pin version/size/SHA-256; implement a local adapter and registry mapping; extend the worker's explicit dispatch; implement preprocessing/tensors/backend requirements/reconstruction/disposal; test genuine inference and quality. Simply changing a manifest URL is insufficient. Publish new adapter support only after successful real tests and required notices.
