## References and decisions

Architecture implementation [lucidrains/BS-RoFormer](https://github.com/lucidrains/BS-RoFormer) is MIT and includes stereo/multiple stems; that does not license every third-party checkpoint. [ZFTurbo model index](https://github.com/ZFTurbo/Music-Source-Separation-Training/blob/main/docs/pretrained_models.md) links weights and configs and has upstream metrics; no metric is a measured Lilith result.

Do not select arbitrary ONNX files. A model needs a reviewed manifest, trusted local adapter, actual graph/tensor validation, preprocessing and postprocessing implementation, license evidence, hash and end-to-end tests. RoFormer additions are a later milestone after the first model is verified. Broad mobile feasibility is not established for any candidate. All RAM figures are unmeasured, not guessed from weight size.
