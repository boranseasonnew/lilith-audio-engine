# Contributing

Use Node24 and the locked dependencies. Run typecheck, lint, build and unit tests. Do not add weights or private recordings to Git. Real inference tests are explicitly separate and require a local authorized fixture. New models need independently reviewed weight terms, pinned hashes, correct adapters and successful real inference. Include reproducible evidence; do not claim quality based only on finite sample checks. Keep the SDK framework independent. Follow AGENTS.md authorship rules when Codex contributes.
